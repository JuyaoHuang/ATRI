## 1. Module Overview

### 1.1 Module Positioning

The TTS (Text-to-Speech) module is the core voice output component of the atri project, responsible for converting text generated by the LLM into natural, fluid speech. As a plugin-style module, TTS acts as a bypass consumer of the LLM stream output, receiving processed text after the translation module, generating audio data, and sending it to the frontend for playback.

**Position in the system**:
```
LLM Output -> Translation Module -> TTS Module -> Audio Playback
                    |
               Live2D Expression Control (parallel)
```

### 1.2 Core Features

1. **Multi-Provider Support**: Supports 6 TTS Providers (3 cloud services + 3 locally deployed)
2. **Unified Interface Abstraction**: Unifies different Provider calling methods through the `TTSInterface` abstract base class
3. **Hot-Swap Switching**: Dynamically switch TTS Providers at runtime without restarting the service
4. **Health Check**: Automatically checks Provider availability at startup and during switching
5. **Voice Management**: Retrieves and manages voice lists from different Providers
6. **Configuration-Driven**: Based on YAML configuration files, supports environment variables
7. **Exception Handling**: 5-layer exception hierarchy for precise error type identification

### 1.3 Design Goals

- **Extensibility**: Adding a new Provider only requires creating a file and adding a decorator, without modifying the factory class
- **Maintainability**: Clear module layering with well-defined responsibilities, easy to understand and maintain
- **High Performance**: Supports model preloading, result caching, and batch processing optimization
- **High Availability**: Health check mechanism ensures Provider availability, with automatic fallback to backup Providers
- **Easy Integration**: RESTful API design, easy for frontend integration

### 2.3 Technology Selection Rationale

**Reasons for choosing these 6 Providers**:

1. **Full Scenario Coverage**:
   - Free solution (edge_tts) suitable for development testing
   - Cloud service solutions (openai_tts, elevenlabs_tts) suitable for production environments
   - Local deployment solutions (gpt_sovits_tts, cosyvoice2_tts) suitable for privacy protection and offline scenarios

2. **Reuse Mature Implementations**:
   - Local Providers directly reuse OLV implementations (gpt_sovits_tts, cosyvoice2_tts)
   - Cloud service Providers reference AIRI implementations (openai_tts, elevenlabs_tts)

3. **Meet Core Requirements**:
   - **Voice Cloning**: gpt_sovits_tts supports reference audio cloning
   - **Chinese Optimization**: cosyvoice2_tts is specifically optimized for Chinese
   - **Zero Cost**: edge_tts is free and requires no API Key
   - **High Quality**: elevenlabs_tts provides top-tier audio quality

4. **Architecture Consistency**:
   - Consistent architecture design with the ASR module
   - Consistent decorator factory pattern with the atri LLM layer

### 3.2 Module Layering

The TTS module adopts a **5-layer architecture**:

1. **Route Layer** (`src/routes/tts.py`)
   - Responsibilities: Handle HTTP requests, parameter validation, response formatting
   - Dependencies: Factory layer

2. **Factory Layer** (`src/tts/factory.py`)
   - Responsibilities: Provider registration, instantiation, management
   - Dependencies: Interface layer

3. **Interface Layer** (`src/tts/interface.py`)
   - Responsibilities: Define unified TTS interface specifications
   - Dependencies: None

4. **Provider Implementation Layer** (`src/tts/providers/`)
   - Responsibilities: Implement specific TTS Providers
   - Dependencies: Interface layer, Exception layer

5. **Exception Layer** (`src/tts/exceptions.py`)
   - Responsibilities: Define the TTS module exception hierarchy
   - Dependencies: None

## 4. Interface Design

### 4.1 TTSInterface Abstract Base Class

`TTSInterface` is the abstract base class for all TTS Providers, defining a unified interface specification.

```python
# src/tts/interface.py

from abc import ABC, abstractmethod
from typing import Optional, AsyncIterator

class TTSInterface(ABC):
    """TTS engine abstract base class"""
    
    @abstractmethod
    async def synthesize(
        self,
        text: str,
        voice_id: Optional[str] = None,
        **kwargs
    ) -> bytes:
        """
        Synchronous speech synthesis (returns complete audio data)
        
        Args:
            text: Text to synthesize
            voice_id: Voice ID (optional, uses default voice)
            **kwargs: Other parameters (pitch, rate, volume, etc.)
        
        Returns:
            bytes: Audio data (MP3/WAV format)
        
        Raises:
            TTSError: TTS synthesis failed
            TTSConnectionError: Network connection failed
            TTSAPIError: API call failed
            TTSRateLimitError: Rate limit exceeded
        """
        raise NotImplementedError
    
    @abstractmethod
    async def synthesize_stream(
        self,
        text: str,
        voice_id: Optional[str] = None,
        **kwargs
    ) -> AsyncIterator[bytes]:
        """
        Streaming speech synthesis (returns audio data stream)
        
        Note: Current implementation is non-streaming output.
        This interface is reserved for future extension.
        Implementations should raise NotImplementedError.
        
        Args:
            text: Text to synthesize
            voice_id: Voice ID
            **kwargs: Other parameters
        
        Yields:
            bytes: Audio data chunks
        
        Raises:
            NotImplementedError: Streaming synthesis not yet implemented
        """
        raise NotImplementedError("Streaming synthesis not yet implemented")
    
    @abstractmethod
    async def get_voices(self) -> list[dict]:
        """
        Get available voice list
        
        Returns:
            list[dict]: Voice list
            [
                {
                    "id": "voice_id",
                    "name": "Voice Name",
                    "language": "zh-CN",
                    "gender": "female",
                    "description": "Voice description",
                    "preview_url": "https://..."  # Optional
                }
            ]
        
        Raises:
            TTSError: Failed to get voice list
        """
        raise NotImplementedError
    
    @abstractmethod
    async def health_check(self) -> bool:
        """
        Health check (called at startup and during switching)
        
        Returns:
            bool: True indicates Provider is available, False indicates unavailable
        
        Note:
            - Cloud services: Check API Key validity, network connection
            - Local services: Check if service is running, if model is loaded
        """
        raise NotImplementedError
```

### 4.2 Method Signatures and Return Values

#### 4.2.1 synthesize() - Synchronous Synthesis

**Method Signature**:
```python
async def synthesize(
    self,
    text: str,
    voice_id: Optional[str] = None,
    **kwargs
) -> bytes
```

**Parameter Description**:
- `text`: Text to synthesize (required)
- `voice_id`: Voice ID (optional, uses default voice if not provided)
- `**kwargs`: Other parameters
  - `pitch`: Pitch adjustment (-100 to +100)
  - `rate`: Speed adjustment (0.5 to 2.0)
  - `volume`: Volume adjustment (0.0 to 2.0)
  - `format`: Output format (mp3/wav/ogg)
  - `sample_rate`: Sample rate (16000/24000/48000)

**Return Value**:
- `bytes`: Complete audio data (binary format)

**Usage Example**:
```python
# Use default voice
audio_data = await tts_engine.synthesize("Hello, world")

# Specify voice and parameters
audio_data = await tts_engine.synthesize(
    text="Hello, world",
    voice_id="alloy",
    rate=1.2,
    pitch=10
)
```

#### 4.2.2 synthesize_stream() - Streaming Synthesis

**Method Signature**:
```python
async def synthesize_stream(
    self,
    text: str,
    voice_id: Optional[str] = None,
    **kwargs
) -> AsyncIterator[bytes]
```

**Current Implementation**:
- ❌ Streaming synthesis not implemented in current version
- ✅ Interface reserved, to be implemented in future versions
- Should raise `NotImplementedError` when implemented

**Design Notes**:
Based on the analysis of OLV, OLV only implemented non-streaming output. Even when `gpt_sovits` is configured with `streaming_mode: true`, OLV waits for the complete audio to be generated before saving it as a file. Therefore, atri adopts the same implementation approach in the current version, with streaming output as a future optimization item.

#### 4.2.4 health_check() - Health Check

**Method Signature**:
```python
async def health_check(self) -> bool
```

**Return Value**:
- `True`: Provider is available
- `False`: Provider is unavailable

**Check Logic**:

**Cloud Service Providers**:
```python
async def health_check(self) -> bool:
    try:
        # Try calling the API (lightweight request)
        response = await self.client.models.list()
        return True
    except Exception as e:
        logger.error(f"Health check failed: {e}")
        return False
```

**Locally Deployed Providers**:
```python
async def health_check(self) -> bool:
    try:
        # Check if service is running
        async with aiohttp.ClientSession() as session:
            async with session.get(
                f"{self.base_url}/health",
                timeout=aiohttp.ClientTimeout(total=5)
            ) as response:
                return response.status == 200
    except Exception as e:
        logger.error(f"Health check failed: {e}")
        return False
```

### 4.3 Interface Design Principles

1. **Uniformity**: All Providers implement the same interface, with consistent calling methods
2. **Async-First**: All methods are asynchronous to avoid blocking the main thread
3. **Optional Parameters**: Use `**kwargs` to support Provider-specific parameters
4. **Explicit Exceptions**: Use custom exception hierarchy for precise error type identification
5. **Backward Compatibility**: Reserve streaming interface, but current implementation is non-streaming

## 5. Factory Pattern Implementation

### 5.1 TTSFactory Decorator Registration Mechanism

`TTSFactory` uses the decorator registration pattern, consistent with the atri LLM layer.

```python
# src/tts/factory.py

from typing import Dict, Type, Optional
from .interface import TTSInterface
from .exceptions import TTSConfigError

class TTSFactory:
    """TTS Provider factory class (decorator registration pattern)"""
    
    _registry: Dict[str, Type[TTSInterface]] = {}
    
    @classmethod
    def register(cls, name: str):
        """
        Decorator: Register a Provider to the factory
        
        Args:
            name: Provider name (e.g., "edge_tts")
        
        Returns:
            Decorator function
        
        Example:
            @TTSFactory.register("edge_tts")
            class EdgeTTS(TTSInterface):
                ...
        """
        def wrapper(provider_class: Type[TTSInterface]):
            if name in cls._registry:
                raise TTSConfigError(f"Provider {name} already registered")
            cls._registry[name] = provider_class
            return provider_class
        return wrapper
    
    @classmethod
    def create(cls, name: str, **kwargs) -> TTSInterface:
        """
        Instantiate a Provider by name
        
        Args:
            name: Provider name
            **kwargs: Provider initialization parameters
        
        Returns:
            TTSInterface: Provider instance
        
        Raises:
            TTSConfigError: Provider not registered
        
        Example:
            tts_engine = TTSFactory.create(
                "edge_tts",
                voice="zh-CN-XiaoxiaoNeural"
            )
        """
        provider_class = cls._registry.get(name)
        if not provider_class:
            available = ", ".join(cls._registry.keys())
            raise TTSConfigError(
                f"Provider {name} not found. "
                f"Available providers: {available}"
            )
        return provider_class(**kwargs)
    
    @classmethod
    def get_registry(cls) -> Dict[str, Type[TTSInterface]]:
        """
        Get registry
        
        Returns:
            Dict[str, Type[TTSInterface]]: Provider registry
        """
        return cls._registry.copy()
    
    @classmethod
    def list_providers(cls) -> list[str]:
        """
        List all registered Providers
        
        Returns:
            list[str]: Provider name list
        """
        return list(cls._registry.keys())
```

#### 5.2.2 Provider Implementation Example

```python
# src/tts/providers/edge_tts.py

from ..factory import TTSFactory
from ..interface import TTSInterface
from ..exceptions import TTSError, TTSConnectionError

@TTSFactory.register("edge_tts")
class EdgeTTS(TTSInterface):
    """Microsoft Edge TTS Provider"""
    
    def __init__(self, voice: str = "zh-CN-XiaoxiaoNeural", **kwargs):
        self.voice = voice
        self.rate = kwargs.get("rate", 1.0)
        self.pitch = kwargs.get("pitch", 0)
    
    async def synthesize(
        self,
        text: str,
        voice_id: Optional[str] = None,
        **kwargs
    ) -> bytes:
        """Synchronous speech synthesis"""
        try:
            import edge_tts
            
            voice = voice_id or self.voice
            rate = kwargs.get("rate", self.rate)
            pitch = kwargs.get("pitch", self.pitch)
            
            # Call edge_tts synthesis
            communicate = edge_tts.Communicate(
                text=text,
                voice=voice,
                rate=f"{rate:+.0%}",
                pitch=f"{pitch:+.0f}Hz"
            )
            
            # Collect audio data
            audio_data = b""
            async for chunk in communicate.stream():
                if chunk["type"] == "audio":
                    audio_data += chunk["data"]
            
            return audio_data
        
        except Exception as e:
            raise TTSError(f"Edge TTS synthesis failed: {e}")
    
    async def synthesize_stream(
        self,
        text: str,
        voice_id: Optional[str] = None,
        **kwargs
    ) -> AsyncIterator[bytes]:
        """Streaming synthesis (currently not implemented)"""
        raise NotImplementedError("Streaming synthesis not yet implemented")
    
    async def get_voices(self) -> list[dict]:
        """Get available voice list"""
        import edge_tts
        
        voices = await edge_tts.list_voices()
        return [
            {
                "id": voice["ShortName"],
                "name": voice["FriendlyName"],
                "language": voice["Locale"],
                "gender": voice["Gender"].lower()
            }
            for voice in voices
        ]
    
    async def health_check(self) -> bool:
        """Health check"""
        try:
            # Try to get voice list
            await self.get_voices()
            return True
        except Exception:
            return False
```

### 5.3 Provider Creation and Initialization

#### 5.3.1 Creating from Configuration File

```python
# src/service_context.py

from src.tts.factory import TTSFactory
from src.config import load_config

class ServiceContext:
    def __init__(self):
        self.config = load_config()
        self.tts_engine = None
    
    def initialize_tts(self):
        """Initialize TTS Provider"""
        tts_config = self.config["tts"]
        active_provider = tts_config["active_provider"]
        provider_config = tts_config["providers"][active_provider]
        
        # Create Provider from configuration
        self.tts_engine = TTSFactory.create(

            **provider_config

```

#### 5.3.2 Runtime Provider Switching

```python
async def switch_tts_provider(
    service_context: ServiceContext,
    provider_name: str
) -> bool:
    """
    Switch TTS Provider
    
    Args:
        service_context: Service context
        provider_name: New Provider name
    
    Returns:
        bool: Whether the switch was successful
    """
    try:
        # Get new Provider configuration
        provider_config = service_context.config["tts"]["providers"][provider_name]
        
        # Create new Provider instance
        new_engine = TTSFactory.create(
            name=provider_config["provider"],
            **provider_config
        )
        
        # Health check
        if not await new_engine.health_check():
            logger.error(f"Provider {provider_name} health check failed")
            return False
        
        # Switch Provider
        service_context.tts_engine = new_engine
        service_context.config["tts"]["active_provider"] = provider_name
        
        logger.info(f"Switched to TTS provider: {provider_name}")
        return True
    
    except Exception as e:
        logger.error(f"Failed to switch TTS provider: {e}")
        return False
```

### 5.4 Hot-Swap Mechanism

The hot-swap mechanism allows dynamically switching TTS Providers at runtime without restarting the service.

**Implementation Steps**:

1. **Create new Provider instance**
2. **Execute health check**
3. **Switch Provider** (atomic operation)
4. **Update configuration**

**Notes**:

- Health check must be executed before switching
- If switching fails, keep the original Provider unchanged
- Requests during the switching process use the old Provider
- Requests after switching completion use the new Provider

## 7. Exception Handling Mechanism

### 7.1 Exception Hierarchy

The TTS module defines **5 exception classes**, forming a clear exception hierarchy:

```python
# src/tts/exceptions.py

class TTSError(Exception):
    """TTS base exception"""
    pass

class TTSConnectionError(TTSError):
    """Network/connection error"""
    pass

class TTSConfigError(TTSError):
    """Configuration error"""
    pass

class TTSAPIError(TTSError):
    """API call error"""
    pass

class TTSRateLimitError(TTSError):
    """Rate limit error"""
    pass
```

### 7.2 Exception Usage Scenarios

#### 7.2.1 TTSError (Base Exception)

**Usage Scenario**: Generic TTS error, used when the error cannot be classified into other exceptions.

**Example**:
```python
async def synthesize(self, text: str, **kwargs) -> bytes:
    try:
        # TTS synthesis logic
        ...
    except Exception as e:
        raise TTSError(f"TTS synthesis failed: {e}")
```

#### 7.2.2 TTSConnectionError (Connection Error)

**Usage Scenario**: Network connection failure, service unreachable.

**Example**:
```python
async def health_check(self) -> bool:
    try:
        async with aiohttp.ClientSession() as session:
            async with session.get(self.base_url) as response:
                return response.status == 200
    except aiohttp.ClientConnectorError as e:
        raise TTSConnectionError(f"Cannot connect to TTS service: {e}")
    except asyncio.TimeoutError:
        raise TTSConnectionError("TTS service connection timeout")
```

#### 7.2.3 TTSConfigError (Configuration Error)

**Usage Scenario**: Missing configuration parameters, format errors, Provider not registered.

**Example**:
```python
def __init__(self, api_key: str, **kwargs):
    if not api_key:
        raise TTSConfigError("API key is required")
    
    if not api_key.startswith("sk-"):
        raise TTSConfigError("Invalid API key format")
    
    self.api_key = api_key
```

#### 7.2.4 TTSAPIError (API Error)

**Usage Scenario**: API call failure, returned error status code.

**Example**:
```python
async def synthesize(self, text: str, **kwargs) -> bytes:
    async with aiohttp.ClientSession() as session:
        async with session.post(self.api_url, json=data) as response:
            if response.status == 400:
                raise TTSAPIError("Invalid request parameters")
            elif response.status == 401:
                raise TTSAPIError("Invalid API key")
            elif response.status == 500:
                raise TTSAPIError("TTS service internal error")
            elif response.status != 200:
                raise TTSAPIError(f"API error: {response.status}")
            
            return await response.read()
```

#### 7.2.5 TTSRateLimitError (Rate Limit)

**Usage Scenario**: API call exceeds rate limit.

**Example**:
```python
async def synthesize(self, text: str, **kwargs) -> bytes:
    async with aiohttp.ClientSession() as session:
        async with session.post(self.api_url, json=data) as response:
            if response.status == 429:
                retry_after = response.headers.get("Retry-After", "60")
                raise TTSRateLimitError(
                    f"Rate limit exceeded. Retry after {retry_after} seconds"
                )
            
            return await response.read()
```

### 7.3 Error Propagation and Handling Strategy

#### 7.3.1 Provider Layer

The Provider layer catches low-level exceptions and converts them to TTS exceptions:

```python
async def synthesize(self, text: str, **kwargs) -> bytes:
    try:
        # Call underlying API
        response = await self.client.synthesize(text)
        return response.content
    
    except ConnectionError as e:
        raise TTSConnectionError(f"Connection failed: {e}")
    
    except ValueError as e:
        raise TTSConfigError(f"Invalid parameter: {e}")
    
    except Exception as e:
        raise TTSError(f"Synthesis failed: {e}")
```

#### 7.3.2 Route Layer

The route layer catches TTS exceptions and returns HTTP error responses:

```python
# src/routes/tts.py

@router.post("/api/tts/synthesize")

    try:
        audio_data = await service_context.tts_engine.synthesize(
            text=request.text,
            voice_id=request.voice_id
        )
        return Response(content=audio_data, media_type="audio/mpeg")
    
    except TTSConnectionError as e:
        raise HTTPException(status_code=503, detail=str(e))
    
    except TTSConfigError as e:
        raise HTTPException(status_code=400, detail=str(e))
    
    except TTSAPIError as e:
        raise HTTPException(status_code=502, detail=str(e))
    
    except TTSRateLimitError as e:
        raise HTTPException(status_code=429, detail=str(e))
    
    except TTSError as e:
        raise HTTPException(status_code=500, detail=str(e))
```

```python
# src/config.py

import os
import yaml
import re

def load_config(config_path: str = "config/tts_config.yaml") -> dict:
    """Load configuration file with environment variable substitution"""
    
    with open(config_path, "r", encoding="utf-8") as f:
        config_str = f.read()
    
    # Substitute environment variables
    def replace_env_var(match):
        var_name = match.group(1)
        default_value = match.group(2) if match.group(2) else None
        
        # Get value from environment variable
        value = os.getenv(var_name, default_value)
        
        if value is None:
            raise ValueError(f"Environment variable {var_name} not set")
        
        return value
    
    # Support ${VAR} and ${VAR:-default} formats
    config_str = re.sub(
        r'\$\{([A-Z_]+)(?::-(.*?))?\}',
        replace_env_var,
        config_str
    )
    
    return yaml.safe_load(config_str)
```

## 9. Health Check Mechanism

### 9.1 Health Check Trigger Timing

The TTS module triggers health checks at **4 timings**:

1. **Startup Check**: Check all Providers when the server starts
2. **Periodic Check**: Background check every 5 minutes (optional)
3. **On-Demand Check**: When user clicks the "Refresh Status" button
4. **Pre-Switch Check**: Mandatory check before user switches Provider

### 9.2 Health Check Implementation Logic

#### 9.2.1 Startup Check

```python
# src/service_context.py

class ServiceContext:
    async def initialize_tts(self):
        """Initialize TTS Provider"""
        tts_config = self.config["tts"]
        
        # Check health status of all Providers
        health_status = {}
        for provider_id, provider_config in tts_config["providers"].items():
            if not provider_config.get("health_check", True):
                continue
            
            try:
                # Create Provider instance
                engine = TTSFactory.create(
                    name=provider_config["provider"],
                    **provider_config
                )
                
                # Execute health check
                is_healthy = await engine.health_check()
                health_status[provider_id] = is_healthy
                
                logger.info(f"TTS Provider {provider_id}: {'healthy' if is_healthy else 'unhealthy'}")
            
            except Exception as e:
                health_status[provider_id] = False
                logger.error(f"TTS Provider {provider_id} initialization failed: {e}")
        
        # Initialize current Provider
        active_provider = tts_config["active_provider"]
        provider_config = tts_config["providers"][active_provider]
        
        self.tts_engine = TTSFactory.create(
            name=provider_config["provider"],
            **provider_config
        )
        
        # If current Provider is unhealthy, try fallback to backup Provider
        if not health_status.get(active_provider, False):
            logger.warning(f"Active TTS provider {active_provider} is unhealthy")
            
            # Find a healthy backup Provider
            for provider_id, is_healthy in health_status.items():
                if is_healthy:
                    logger.info(f"Falling back to TTS provider: {provider_id}")
                    provider_config = tts_config["providers"][provider_id]
                    self.tts_engine = TTSFactory.create(
                        name=provider_config["provider"],
                        **provider_config
                    )
                    break
```

### 9.3 Result Caching Strategy

To avoid frequent health checks, implement a **5-minute TTL cache**:

```python
# src/tts/health_cache.py

from datetime import datetime, timedelta
from typing import Dict, Optional

class HealthCheckCache:
    """Health check result cache"""
    
    def __init__(self, ttl_seconds: int = 300):
        self.ttl_seconds = ttl_seconds
        self._cache: Dict[str, tuple[bool, datetime]] = {}
    
    def get(self, provider_id: str) -> Optional[bool]:
        """Get cached health status"""
        if provider_id not in self._cache:
            return None
        
        is_healthy, timestamp = self._cache[provider_id]
        
        # Check if expired
        if datetime.now() - timestamp > timedelta(seconds=self.ttl_seconds):
            del self._cache[provider_id]
            return None
        
        return is_healthy
    
    def set(self, provider_id: str, is_healthy: bool):
        """Set health status"""
        self._cache[provider_id] = (is_healthy, datetime.now())
    
    def invalidate(self, provider_id: str):
        """Invalidate cache"""
        if provider_id in self._cache:
            del self._cache[provider_id]
    
    def clear(self):
        """Clear cache"""
        self._cache.clear()

# Global cache instance
health_cache = HealthCheckCache(ttl_seconds=300)
```

**Using the cache**:

### 11.2 Result Caching

For the same text and parameters, cache synthesis results to avoid redundant computation.

```python
# src/tts/cache.py

from functools import lru_cache
import hashlib

class TTSCache:
    """TTS result cache"""
    
    def __init__(self, max_size: int = 100):
        self.max_size = max_size
        self._cache: dict[str, bytes] = {}
    
    def _generate_key(self, text: str, voice_id: str, **kwargs) -> str:
        """Generate cache key"""
        key_str = f"{text}:{voice_id}:{kwargs}"
        return hashlib.md5(key_str.encode()).hexdigest()
    
    def get(self, text: str, voice_id: str, **kwargs) -> bytes | None:
        """Get from cache"""
        key = self._generate_key(text, voice_id, **kwargs)
        return self._cache.get(key)
    
    def set(self, text: str, voice_id: str, audio_data: bytes, **kwargs):
        """Set cache"""
        if len(self._cache) >= self.max_size:
            # LRU eviction
            self._cache.pop(next(iter(self._cache)))
        
        key = self._generate_key(text, voice_id, **kwargs)
        self._cache[key] = audio_data
    
    def clear(self):
        """Clear cache"""
        self._cache.clear()

# Global cache instance
tts_cache = TTSCache(max_size=100)
```

```python
                text=text,
                voice_id=request.voice_id
            )
            results.append({
                "text": text,
                "success": True,
                "audio": base64.b64encode(audio_data).decode()
            })
        except Exception as e:
            results.append({
                "text": text,
                "success": False,
                "error": str(e)
            })
    
    return {"results": results}
```

### 11.4 Memory Management

For synthesizing large texts, process in segments to avoid memory overflow.

```python
def split_text(text: str, max_length: int = 500) -> list[str]:
    """Split text into segments"""
    if len(text) <= max_length:
        return [text]
    
    # Split by sentences
    sentences = re.split(r'[.!?\n]', text)
    
    chunks = []
    current_chunk = ""
    
    for sentence in sentences:
        if len(current_chunk) + len(sentence) <= max_length:
            current_chunk += sentence
        else:
            if current_chunk:
                chunks.append(current_chunk)
            current_chunk = sentence
    
    if current_chunk:
        chunks.append(current_chunk)
    
    return chunks

async def synthesize_long_text(text: str, **kwargs) -> bytes:
    """Synthesize long text"""
    chunks = split_text(text, max_length=500)
    
    audio_chunks = []
    for chunk in chunks:
        audio_data = await service_context.tts_engine.synthesize(
            text=chunk,
            **kwargs
        )
        audio_chunks.append(audio_data)
    
    # Merge audio
    return b"".join(audio_chunks)
```

## 15. Summary

### 15.1 Design Highlights

1. **Decorator Factory Pattern**: Adding a new Provider does not require modifying the factory class, highly extensible
2. **Unified Interface Abstraction**: All Providers implement the same interface, with consistent calling methods
3. **Health Check Mechanism**: 4 trigger timings + 5-minute cache, ensuring high availability
4. **5-Layer Exception Hierarchy**: Precise error type identification, easy for debugging and monitoring
5. **Configuration-Driven Design**: Supports environment variables, easy for deployment and management
6. **Performance Optimization**: Model preloading, result caching, batch processing support
