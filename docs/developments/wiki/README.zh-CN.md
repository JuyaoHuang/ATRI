# Wiki 预发布区

本目录保存准备迁移到 GitHub Wiki 的整理稿。

Wiki 文档应面向读者，而不是保留原始开发流水。写作时优先提供清晰叙事：

- 背景
- 问题
- 方案
- 实现路径
- 验收
- 后续改进

适合放置：

- 整理后的开发 blog
- 面向外部读者的架构文章
- 模块介绍
- troubleshooting

不适合放置：

- 未完成的设计草稿
- 大段原始对话
- 临时 debug 日志
- 某次开发的逐日流水

原始开发过程应先保存在 `../features/`，整理成熟后再进入本目录。
